## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/amanshafaqat/portfolio.git
```

Navigate into the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## 🔧 Available Scripts

## 🔐 Environment Variables

If environment variables are required for specific features, create a `.env.local` file in the project root.

Example:

```env
NEXT_PUBLIC_API_URL=your_api_url
```

Do not commit private API keys, passwords, tokens, or other secrets to GitHub.
